# Contributing

Keep chapter changes original, technical, and consistent with the reference-geometry conventions. Mark illustrative values and separate patent disclosures from measured evidence. Link a primary source beside any new sourced claim and update the evidence map. Record source scope and limitations.

Preserve the 16-chapter/four-part and A–G appendix structure unless the editorial scope is deliberately changed. Recompute examples when assumptions change, update selected answers, run validation, and regenerate the compiled e-book. Do not commit credentials or private fabrication data.

Use the commands in [README](README.md). The generated volumes are committed so readers can obtain them without a build environment.
